# 0002 — Servidores abertos + equipes por Bond
- Status: Aceita
- Data: 2026-11-11
## Contexto
Servidores abertos permitem jogar com desconhecidos, mas abrem espaço para atrapalhar os outros.
## Decisão
Jogadores só interagem fisicamente (gancho, colisão) com quem está no mesmo **Bond** (equipe
formada por consentimento dos dois lados). Fora do Bond, ninguém afeta ninguém.
## Consequências
O servidor é quem valida todo efeito entre jogadores. Ver GAME_DESIGN §3.1.
