# 0003 — O gancho puxa os dois jogadores
- Status: Aceita
- Data: 2026-11-11
## Decisão
Quando um jogador engancha um parceiro do Bond, a força age nos **dois** (um vai em direção ao outro).
## Consequências
O gancho em jogador passa pelo servidor. O feel local é previsto no cliente e corrigido pelo servidor.
