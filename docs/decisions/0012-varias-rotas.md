# 0012 — Mapas com várias rotas até o final
- Status: Aceita
- Data: 2026-11-12
## Decisão
Cada mapa é um "labirinto" 2.5D: há **várias formas de chegar ao final** (rotas que se dividem e
se juntam, atalhos difíceis, caminhos mais seguros e lentos). Refina a decisão 0010.
## Consequências
- Level design pensa em rotas: pelo menos uma segura, uma rápida/arriscada.
- Rotas podem exigir mecânicas diferentes (gancho, gelo, parceiro/objeto solo).
- Ranking de tempo recompensa quem descobre atalhos.
