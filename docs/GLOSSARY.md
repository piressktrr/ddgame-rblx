# Glossário

| Termo | Significado |
|---|---|
| **Bond** | Equipe formada por consentimento. Só membros do mesmo Bond interagem fisicamente. |
| **Gancho** | Gancho mágico. Prende em superfícies `Hookable` ou no parceiro do Bond (puxa os dois). |
| **Congelar / Descongelar** | Efeito das zonas `FreezeZone` / `UnfreezeZone` sobre o jogador. |
| **Modo Solo / Equipe** | `PlayMode` "Solo" ou "Team". Rankings separados. |
| **Objetos mágicos** | Itens que substituem o parceiro no solo (nomes provisórios, ver Q4). |
| **Tags** | Etiquetas do CollectionService que dão comportamento às peças do mapa (lista em `Config.Tags`). |
| **Service / Controller** | Módulo do servidor / do cliente carregado pelo Loader (`Init` e `Start`). |
| **Marco (M0–M6)** | Etapas do roadmap em ARCHITECTURE.md. |
| **ADR** | Registro de decisão em `docs/decisions/`. |
