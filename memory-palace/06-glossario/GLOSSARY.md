# Glossário

| Termo | Significado |
|---|---|
| **Bond** | Sistema de equipe por consentimento. **Suspenso** (ADR 0013): hoje todos interagem com todos. |
| **Bouncer** | Pistola mágica de impulso, pega num ponto do mapa (ADR 0017). |
| **Lâmina mágica** | Empurrão corpo a corpo (ADR 0019). |
| **HookOnce / NoHook** | Superfície verde (gruda 1x por jogador) / superfície não-grudável. |
| **Gancho** | Gancho mágico. Gruda em tudo, menos `NoHook`; em jogador, puxa os dois. |
| **Congelar / Descongelar** | Efeito das zonas `FreezeZone` / `UnfreezeZone` sobre o jogador. |
| **Solo / grupo** | Mesmo mapa; quem está sozinho tem objetos mágicos. Ranking sempre pessoal (ADR 0018, 0020). |
| **Objetos mágicos** | Itens que substituem o parceiro no solo (nomes provisórios, ver Q4). |
| **Tags** | Etiquetas do CollectionService que dão comportamento às peças do mapa (lista em `Config.Tags`). |
| **Service / Controller** | Módulo do servidor / do cliente carregado pelo Loader (`Init` e `Start`). |
| **Marco (M0–M6)** | Etapas do roadmap em ARCHITECTURE.md. |
| **ADR** | Registro de decisão em `memory-palace/02-decisoes/`. |
