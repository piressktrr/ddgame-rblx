# 0023 — Solo primeiro; Bond volta depois do MVP
- Status: Aceita (refina 0013)
- Data: 2026-11-12
## Contexto
A maioria das pessoas joga sozinha.
## Decisão
- MVP foca no jogo **solo**: objetos mágicos sempre ativos para todos.
- Bond volta **depois do MVP**, como formação de grupo, mas **sem proteção**: grupos diferentes
  continuam podendo se atrapalhar (o caos é parte do jogo).
- Interação entre jogadores (gancho em jogador, lâmina, Bouncer) continua valendo no MVP.
