# 0021 — Cores do descongelar e do não-grudável
- Status: Aceita (completa 0015)
- Data: 2026-11-12
## Decisão
- Descongelar: **laranja-brasa** `#FF8A1F` (oposto do azul-gelo; legível para daltônicos).
- Não-grudável: **roxo** (cor de "proibido" mágico). Tom exato no greybox.
- Vermelho fica só para zona mortal. Zona mortal é grudável como qualquer superfície comum.
