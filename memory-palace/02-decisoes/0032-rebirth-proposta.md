# 0032 — Ciclo de rebirth (proposta para analisar)
- Status: **Proposta** (dono pediu para analisar; não decidido)
- Data: 2026-11-15
## Contexto
O dono observou em "+1 Speed Keyboard Escape", "Escape Tsunami for Brainrots" e "Steal a Soul": o
jogador avança nas fases e depois **recomeça (rebirth)** para ganhar algo permanente que libera fases
mais à frente, perks ou poderes. Itens baratos aceleram esse ciclo, e isso monetiza bem.
## Proposta
- Atributo que cresce: **velocidade** e/ou **algo do gancho** (alcance, força do puxão, recarga). Ver Q23.
- Rebirth: zera o atributo, dá um multiplicador permanente e/ou um perk; alguns estágios só abrem
  depois de N rebirths.
- Loja com itens baratos: multiplicador temporário, perk de gancho, cosméticos.
## Pontos a analisar
Ranking justo (ADR 0028), quanto tempo até o 1º rebirth, como o estágio "trancado" aparece no mapa.
